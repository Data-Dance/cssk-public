CZ Supplier Reliability — ADIS provider

Unreliable VAT payer & published bank accounts from the MFČR ADIS web service

This module implements the Czech country provider for l10n_cssk_payment_reliability. It queries the Czech Financial Administration (Finanční správa ČR) ADIS SOAP web service (rozhraniCRPDPH) to tell whether a supplier is an unreliable VAT payer (nespolehlivý plátce) and to fetch the supplier's registered bank accounts (zveřejněné účty). This supports guarantor liability for unpaid VAT (§109) checks on vendor bills. No API key is required — the service is open.

Key features

  • Calls the published ADIS endpoint adisrws.mfcr.cz/.../rozhraniCRPDPH.rozhraniCRPDPHSOAP, operation getStatusNespolehlivyPlatce.
  • Tax reliability mapping: nespolehlivyPlatce ANO → unreliable, NE → reliable, NENALEZEN → unknown.
  • Registered bank accounts: standardníÚčet (předčíslí/číslo/kódBanky) is converted to its IBAN so it matches the bank account on the bill; nestandardníÚčet (already an IBAN) is taken as-is.
  • Returns no result on network or parsing errors, leaving the supplier status unknown rather than failing.
  • No API key needed — the MFČR service is open and free to query.

Usage

Install this module alongside l10n_cssk_payment_reliability. For partners whose country is set to Czech Republic (CZ) and who have a VAT/DIČ filled in, the shared reliability check automatically routes to this ADIS provider. There is nothing to configure and no API key to obtain.
