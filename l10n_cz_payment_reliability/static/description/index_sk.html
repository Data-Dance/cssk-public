CZ Supplier Reliability — poskytovateľ ADIS

Nespolehlivý plátce a zveřejněné účty z webovej služby ADIS MFČR

Tento modul implementuje český poskytovateľ pre l10n_cssk_payment_reliability. Dopytuje sa webovej služby SOAP ADIS českej Finančnej správy (rozhraniCRPDPH), aby zistil, či je dodávateľ nespoľahlivý platiteľ, a aby získal jeho zveřejněné účty z českého registra nespoľahlivých platiteľov DPH (nespolehlivý plátce). To podporuje kontrolu ručenia za daň (§109) na prijatých faktúrach. Nie je potrebný žiadny API kľúč — služba je otvorená.

Kľúčové funkcie

  • Volá zverejnený koncový bod ADIS adisrws.mfcr.cz/.../rozhraniCRPDPH.rozhraniCRPDPHSOAP, operáciu getStatusNespolehlivyPlatce.
  • Mapovanie spoľahlivosti na daňové účely: nespolehlivyPlatce ANO → nespoľahlivý, NE → spoľahlivý, NENALEZEN → neznámy.
  • Zveřejněné účty: standardníÚčet (předčíslí/číslo/kódBanky) sa prevedie na IBAN, aby zodpovedal bankovému účtu na faktúre; nestandardníÚčet (už vo formáte IBAN) sa preberá tak, ako je.
  • Pri chybe siete alebo spracovania nevracia žiadny výsledok — stav dodávateľa zostáva neznámy, namiesto toho, aby modul zlyhal.
  • Žiadny API kľúč nie je potrebný — služba MFČR je otvorená a dopyty sú zdarma.

Použitie

Nainštalujte tento modul spolu s l10n_cssk_payment_reliability. Pri partneroch, ktorí majú ako krajinu nastavenú Českú republiku (CZ) a vyplnené DIČ, zdieľaná kontrola spoľahlivosti automaticky použije tento poskytovateľ ADIS. Nie je čo nastavovať ani žiadny API kľúč zaobstarávať.
