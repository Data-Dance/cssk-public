CZ Supplier Reliability — poskytovatel ADIS

Nespolehlivý plátce a zveřejněné účty z webové služby ADIS MFČR

Tento modul implementuje český poskytovatel pro l10n_cssk_payment_reliability. Dotazuje se webové služby SOAP ADIS Finanční správy ČR (rozhraniCRPDPH), aby zjistil, zda je dodavatel nespolehlivý plátce, a aby získal jeho zveřejněné účty z Registru nespolehlivých plátců DPH. To podporuje kontrolu ručení za daň (§109) na přijatých fakturách. Není potřeba žádný API klíč — služba je otevřená.

Klíčové funkce

  • Volá zveřejněný koncový bod ADIS adisrws.mfcr.cz/.../rozhraniCRPDPH.rozhraniCRPDPHSOAP, operaci getStatusNespolehlivyPlatce.
  • Mapování spolehlivosti pro daňové účely: nespolehlivyPlatce ANO → nespolehlivý, NE → spolehlivý, NENALEZEN → neznámý.
  • Zveřejněné účty: standardníÚčet (předčíslí/číslo/kódBanky) je převeden na IBAN, aby odpovídal bankovnímu účtu na faktuře; nestandardníÚčet (již ve formátu IBAN) je převzat tak, jak je.
  • Při chybě sítě nebo zpracování nevrací žádný výsledek — stav dodavatele zůstane neznámý, místo aby modul selhal.
  • Žádný API klíč není potřeba — služba MFČR je otevřená a dotazy jsou zdarma.

Použití

Nainstalujte tento modul společně s l10n_cssk_payment_reliability. U partnerů, kteří mají jako zemi nastavenou Českou republiku (CZ) a vyplněné DIČ, sdílená kontrola spolehlivosti automaticky použije tento poskytovatel ADIS. Není co nastavovat ani žádný API klíč obstarávat.
