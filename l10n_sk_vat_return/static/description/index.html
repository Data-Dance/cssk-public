Slovakia — VAT Return (Daňové priznanie k DPH)

The Slovak VAT return (DPHv25), computed CE-clean from l10n_sk tax tags, with FS SR DPH XML export

This app produces the Slovak VAT return (daňové priznanie k DPH, form DPHv25) on top of the shared l10n_cssk_vat_return_base framework. Line definitions mirror the l10n_sk DPH report tag formulas, so the per-line values match what Odoo's own report would compute — but with a Community-clean evaluator that does not depend on account_reports.

It also bundles a § 53b correction wizard for the input-VAT adjustment on long-overdue vendor bills, and exports the Finančná správa DPH XML.

Key features

  • Output base/tax per category — sk01, sk03 (standard), sk05 (reduced).
  • Deductible (input) tax — sk19, sk20.
  • Aggregates: total output base/tax, total deductions, net VAT.
  • FS SR DPH XML export (template + stand-in XSD — replace with the official schema before live filing).
  • § 53b correction of deducted VAT on vendor bills unpaid more than 100 days past due, with a re-claim mirror entry once the bill is paid again.

Status — functional core. The net-payable lines that Odoo computes with sum / custom engines (sk_30+) are out of scope of the simple tags+aggregate evaluator and need extended-engine support or manual entry. The shipped XSD is a stand-in; line semantics and the net-payable computation still need accountant validation.

Usage

Create a VAT return for a period, compute it to populate the lines from the period's postings against the real l10n_sk tax tags, review the per-line values, then export the DPH XML for the FS portal. For long-overdue vendor bills, run the § 53b wizard (below) to generate the r29 correction before computing the return.

Wizards

§ 53b correction of deducted VAT (Accounting ▸ Accounting ▸ Oprava odpočítanej dane (§ 53b))

What it does: generates the § 53b correction of deducted input VAT (line r29 of the VAT return) for received vendor bills left unpaid more than 100 days past their due date. The correction is proportional to the unpaid fraction of the bill and carries the r29 tax tag so the return picks it up.

How to use: open the menu item, choose the as-of date (the 100-day threshold is measured to this date), the overdue-days threshold (default 100), the correction journal and the cost counter-account (typically 548). The qualifying bills are listed read-only; press Generate corrections to post one correction entry per bill. When a corrected bill is paid again, use the bill's § 53b re-claim action to post the mirror entry that re-deducts the VAT.
