Slovakia — Peppol BIS Billing 3.0 (eFaktúra)

Peppol BIS Billing 3.0 / UBL 2.1 e-invoice export for Slovak companies

This module enables the Peppol BIS Billing 3.0 (UBL 2.1 / EN 16931) e-invoice format for Slovak companies, ahead of the mandatory Slovak e-invoicing regime (domestic B2B from 1 January 2027).

Slovakia has no national billing CIUS: the mandated invoice is unmodified Peppol BIS Billing 3.0, which Odoo's account.edi.xml.ubl_bis3 already produces correctly. This module is therefore deliberately thin — it only fills the Slovak gaps.

Key features

  • Format registration. SK is missing from Odoo core's PEPPOL_DEFAULT_COUNTRIES, so the generic Peppol format is not offered for Slovak partners. This module registers ubl_bis3_sk for SK and makes it the auto-suggested default for Slovak partners.
  • Extension point. account.edi.xml.ubl_sk subclasses the generic Peppol builder — a stable place to add Slovak-specific behaviour later, with no CustomizationID deviation.
  • Variabilný symbol (VS). Mapped onto cac:PaymentMeans/cbc:PaymentID (BT-83): the explicit payment reference if set, otherwise the numeric tail of the invoice number, normalised to the last 10 digits.
  • Auto-installs once a Slovak chart and the UBL/CII engine are both present, mirroring l10n_ro_edi / l10n_pl_edi.

Out of scope (handled by a certified Peppol Access Point, not the ERP): the Slovak Tax Data Document (TDD, urn:peppol:taxdata:sk-1) and the 5-corner CTC reporting to Finančná správa.

Usage

Slovak partners get invoice_edi_format = "Slovakia (Peppol BIS 3.0)" automatically. Ensure the company has a valid IČ DPH (VAT) and a Slovak IBAN on the relevant bank account, then send the invoice as usual — the UBL 2.1 file is generated in the Peppol BIS Billing 3.0 format.
