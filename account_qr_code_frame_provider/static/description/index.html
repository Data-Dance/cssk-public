QR Code Frame Provider

A reusable hook to render payment QR codes inside a branded frame image

This module provides the plumbing to composite a payment QR code onto a frame image (for example a "QR Platba" / "PAY by square" branded frame). It overrides res.partner.bank._get_qr_code_base64 so that, when a frame is configured, the generated QR is resized and pasted onto the frame and returned as a single PNG data URI.

On its own the module exposes an extension hook (_get_qr_code_frame_generation_params) that returns None by default — a country/scheme module supplies the actual frame image, box size, border and placement. It also removes the default Odoo logo from the invoice-report QR code.

Key features

  • Composites the payment QR onto a configurable frame image (frame, box size, border, resize and x/y placement), returned as a PNG data URI.
  • Extension hook _get_qr_code_frame_generation_params(qr_method) — returns None by default, so a downstream module plugs in the concrete frame parameters per QR method.
  • Removes the default Odoo logo from the invoice-report QR code.
  • Transparent in the absence of a frame: falls back to the standard QR rendering.

Usage

Install as a dependency of a module that overrides _get_qr_code_frame_generation_params to return the frame image and layout for a given QR method. With those parameters present, every invoice that renders a payment QR code will show it inside the configured frame instead of the plain code.
