CZ Control Statement (Kontrolní hlášení / DPHKH1)

Czech VAT control statement on the shared KV/KH framework, with the 10 000 CZK split and the EPO Pisemnost / DPHKH1 XML export

The Czech country layer for the shared control-statement framework (l10n_cssk_kv_kh_base). A line-level resolver classifies posted move lines into the Kontrolní hlášení (DPHKH1) sections, and the module exports the EPO Pisemnost / DPHKH1 XML for submission. This is the Czech Kontrolní hlášení (KH) — a different form from the Slovak Kontrolný výkaz DPH (KV DPH).

Key features

  • A line-level resolver classifies posted move lines into the KH sections.
  • The per-document 10 000 CZK threshold splits the detail sections (A4/B2, over) from the aggregates (A5/B3, up to).
  • Reverse-charge supplies and acquisitions (§92a) are routed to A1/B1; EU acquisitions to A2.
  • Exports the EPO Pisemnost / DPHKH1 XML: VetaD/VetaP, the per-document VetaA1/A2/A4/B1/B2 rows, the VetaA5/B3 aggregates, and the VetaC control totals computed from the sections.

Usage

Install the module on a Czech company and create a control statement for the reporting period. Computing the lines populates the A1–B3 sections from the posted move lines, applying the 10 000 CZK per-document split between the detail and aggregate sections. Export the statement to produce the EPO Pisemnost / DPHKH1 XML, validated against the official EPO DPHKH1 XSD (data/dphkh1_epo2.xsd) loaded onto the version record. Scope note (v1): the resolver decision tree — especially the §92a reverse-charge commodity list and the §44 bad-debt corrections — needs CZ-accountant validation.
