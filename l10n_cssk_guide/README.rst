**One page to start from — the first steps, then the guide of every localization module on this server, by topic.**

What it is for
================

Every module of the Czech and Slovak localization has its own guide. This module adds the page that ties them together: the first steps for a new company, then every guide sorted by topic.

Opening it
============

*Accounting → Configuration → Guides* opens the page in a new tab.

- It is in your language when that is English, Slovak or Czech; the switch at the top changes it.

- It shows the modules of your company's country and the shared ones. *Show* switches between the Czech Republic, Slovakia and all.

- Under some topics, **task guides** come first: how to get a job done, such as running a management report, across Odoo's own screens, the OCA modules and ours, written from a Slovak or Czech accountant's point of view, for Odoo Community.

- Under each topic, the installed modules come first. A module that is on the server but not installed is listed too, marked *not installed*: install it from *Apps* when you need it.

It lists what is on this server, so it covers every module your provider delivered, whatever package it came in. It installs itself with the shared core and has no settings.
