Tax Depreciation — CZ/SK dual depreciation

A second, non-posted tax-depreciation board (daňové odpisy) alongside accounting depreciation

Czech and Slovak income-tax law require every asset to carry two parallel depreciation plans: the accounting plan (posted to account 551) and the tax plan (daňové odpisy), which is a tax-base figure only and is never posted to the general ledger. It only adjusts the income-tax base (DPPO add-back / deduction).

This app adds the tax board, computed by a verified pure-Python engine implementing CZ §31/§32/§30a and SK §27/§28. Install core + one bridge (account_asset_tax_ee for Enterprise, account_asset_tax_oca for OCA/Community) + the country data layer (l10n_cz_account_asset_tax / l10n_sk_account_asset_tax).

Key features

  • Parallel tax depreciation board per asset, independent of the posted accounting plan.
  • Statutory engine with no Odoo import (engine/depreciation.py), unit-tested in isolation and reused unchanged by both framework bridges.
  • Country coefficients/groups supplied by thin data layers (CZ §31/§32/§30a, SK §27/§28).
  • Lifecycle events: technical improvement, suspension, disposal — re-plan from the event date.
  • Period reconciliation for the DPPO (§23 add-back / deduction) with optional deferred-tax posting and XLSX/PDF export.

Usage

Open any asset to see its tax board next to the accounting board. Use the wizards below to compute boards in batch, backfill mid-life assets, record events, file a year, and reconcile the period for the income-tax return.

Wizards

Compute Tax Depreciation Boards

What it does: (re)computes the tax board for a selection of assets.

How to use: select assets (or open the wizard), run Compute; the boards are rebuilt from each asset's entry value, in-service date, group and method.

Backfill Tax Depreciation

What it does: initialises the tax board on an asset that is already part-way through its life.

How to use: open the asset, launch Backfill, enter the years already elapsed / accumulated tax depreciation, then Backfill to seed the board.

Tax Depreciation Event Wizard

What it does: records a lifecycle event — technical improvement, suspension or disposal — and re-plans the board from that point.

How to use: on the asset, open the event wizard, pick the event type and date, enter any amount (e.g. improvement value), then Apply.

Close Tax Depreciation Year

What it does: freezes the board up to a filed fiscal year so later edits cannot alter an already-submitted DPPO.

How to use: open Close Tax Depreciation Year, choose the year, then File Year.

Tax Depreciation Reconciliation (DPPO)

What it does: reconciles accounting vs tax depreciation for a fiscal period — the §23 add-back / deduction feeding the income-tax return.

How to use: open the reconciliation wizard for the period, Compute, review the per-asset lines, optionally Post deferred tax, and Export XLSX / Print PDF.
