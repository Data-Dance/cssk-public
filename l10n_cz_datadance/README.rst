============================================
Czech Accounting Localization — full suite
============================================

.. image:: https://img.shields.io/badge/licence-AGPL--3-blue.png
   :alt: License: AGPL-3

**Installs the Czech statutory localization in one step and offers the optional pieces as switches in the settings.**

What it is for
================

The Czech localization is split into many modules so that each company installs only what it needs. This module is the one-click way in: installing it brings the statutory core for a Czech company, and adds switches for the optional parts. It has no screens or data of its own.

What it installs
==================

.. list-table::
   :header-rows: 1

   * - Area
     - Module
   * - Shared core: settings, tax offices, filing life cycle
     - ``l10n_cssk_core``
   * - Czech statutory base
     - ``l10n_cz_statutory``
   * - VAT return (*přiznání k DPH*, DPHDP3)
     - ``l10n_cz_vat_return``
   * - Control statement (*kontrolní hlášení*, DPHKH1)
     - ``l10n_cz_kh``
   * - EC sales list (*souhrnné hlášení*, DPHSHV)
     - ``l10n_cz_ec_sales``
   * - Czech invoice layout
     - ``l10n_cz_invoice``
   * - Partner balances and offsetting (*saldokonto*, *zápočet*)
     - ``l10n_cssk_partner_balances``
   * - VIES check of EU VAT numbers
     - ``l10n_cssk_vies``
   * - Accruals (*dohadné položky*)
     - ``l10n_cssk_accrual``

Each of these modules has its own guide.

Optional pieces
=================

*Accounting → Configuration → Settings*, block **Czech / Slovak Localization**. Tick a switch and save: Odoo installs the module. Unticking it uninstalls the module again.

.. list-table::
   :header-rows: 1

   * - Switch
     - Installs
     - Notes
   * - Exchange-rate sync (ČNB)
     - ``currency_rate_update_cz``
     - daily rates of the Czech National Bank; Community only
   * - Časové rozlišení (deferrals)
     - ``l10n_cz_account_cutoff``
     - prepaid and deferred expenses and revenues (381–385); Community only
   * - Supplier reliability check
     - ``l10n_cz_payment_reliability``
     - checks an unreliable VAT payer and the published bank account before you pay
   * - Dual depreciation
     - ``l10n_cz_account_asset_tax``
     - tax depreciation alongside accounting depreciation
   * - Method A inventory
     - ``l10n_cz_stock_account_method_a``
     - perpetual inventory accounting (*způsob A*); delivered in a separate repository
   * - Advance invoices
     - ``l10n_cz_sale_order_advance_invoice``
     - *zálohové faktury* and tax documents for received payments
   * - Účetní závěrka (Rozvaha, VZZ)
     - ``l10n_cz_fs``
     - balance sheet and profit and loss account
   * - Přiznání k dani z příjmů (DPPDP9)
     - ``l10n_cz_dppo``
     - corporate income-tax return

On Odoo Enterprise the exchange-rate and deferral switches are hidden, because Enterprise has its own automatic exchange rates and deferred revenue and expense.

Limitations
=============

- A switch for a module that is not on the server (Method A, the financial statements and the income-tax return are delivered separately) does nothing.

- Uninstalling this module does not uninstall what it brought in.

- The setting help for *Method A inventory* says perpetual inventory is required for audited companies; this guide does not confirm that statement.
