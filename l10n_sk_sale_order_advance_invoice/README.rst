====================================
Advance Invoices — Slovak Accounts
====================================

.. image:: https://img.shields.io/badge/licence-AGPL--3-blue.png
   :alt: License: AGPL-3

**Wires the advance-invoice settings to the Slovak chart of accounts.**

Fills in the advance-invoice settings for every company with the Slovak chart of accounts: it creates the reconcilable clearing account 324001 *Prijaté preddavky – zúčtovanie (daňový doklad)* (in English *Advances received – clearing (tax document)*), uses 324000 *Prijaté preddavky* for short-term and 475000 *Dlhodobé prijaté preddavky* for long-term received advances, and names the TDADV journal *Faktúry k prijatým platbám*.

Install it together with the advance invoices module on a Slovak company. It runs at installation and again whenever the Slovak chart is loaded later, for example for a new company, and fills only settings that are still empty.
