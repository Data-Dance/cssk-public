Slovakia — Financial Statements (Súvaha / VZS)

Slovak balance sheet and profit & loss statement on the shared l10n_cssk_fs_base framework, with the official UZPODv14 XML export

This app produces the concrete Slovak Súvaha (balance sheet) and Výkaz ziskov a strát (profit & loss, druhové členenie) on top of the shared l10n_cssk_fs_base framework, computed CE-clean (no account_reports).

It maps every account of the l10n_sk účtová osnova to exactly one statutory leaf line (a partition verified in the tests), so the aggregates reconcile: SPOLU MAJETOK = SPOLU VLASTNÉ IMANIE A ZÁVÄZKY and the result of the period equals výnosy − náklady. The current-year result (A.V) is computed from triedy 5/6, so the súvaha ties out before the result is closed to účtu 431.

Key features

  • Full statutory line structure per the Opatrenie MF SR pre podnikateľov účtujúcich v sústave podvojného účtovníctva — semantic Súvaha and VZS for on-screen review.
  • Account-code line mapping with a verified partition (every account maps to exactly one leaf line) and a comparison period.
  • Current-year result (A.V) computed from triedy 5/6 so the balance sheet ties out before the result is closed to účtu 431.
  • Official UZPODv14 export (l10n.sk.uzpod): the combined účtovná závierka dokument — Súvaha Úč POD 1 (r001–r145 with Brutto / Korekcia / Netto) plus Výkaz ziskov a strát Úč POD 2 (r01–r61) — built CE-clean from account.move.line and validated against the official data/uzpod-2014.xsd (FS SR).
  • Row→account formulas (models/uzpod14_rows.py) mirror the authoritative statutory mapping.

Accountant note: confirm the NACE code and header fields on the company and validate the row mapping with a Slovak accountant before live filing. On Enterprise, SK FS may instead defer to the native UZPODv14 export.

Usage

Create a financial-statements record for a fiscal period, compute it to populate the line structure from the period's postings, review the Súvaha and VZS detail with the comparison period, then export the official UZPODv14 dokument XML for the FS portal. The semantic statements remain available for on-screen review independently of the fileable export.
