==============================
CZ VAT Status — Sales Orders
==============================

.. image:: https://img.shields.io/badge/licence-AGPL--3-blue.png
   :alt: License: AGPL-3

**Sales order lines propose the taxes the Czech company's VAT status allows on the order date.**

When the company records a VAT status history, a sales order line proposes the taxes that status allows on the order date — for example no VAT while the company is a neplátce. It is only a proposal: the invoice made from the order is decided again by its own DUZP, and cannot be posted with taxes that no longer fit.

It installs itself when both Sales and the CZ VAT status module are installed, and has no settings.
