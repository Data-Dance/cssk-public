## Salary rules

`BASIC` → `MEAL` → `GROSS` → `SOCIALEE` / `SOCIALER` →
`HEALTHEE` / `HEALTHER` → `TAXBASE` → `INCOMETAX` → `TAXCREDIT` →
`CHILDBEN` / `CHILDBONUS` → statutory deductions → `NET` → reporting
totals → `EMPLOYERCOST`.
