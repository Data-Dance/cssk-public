Česká republika — Přiznání k DPH (DPHDP3)

České přiznání k DPH sestavené z daňových značek l10n_cz a exportované jako XML EPO Pisemnost/DPHDP3

Tato aplikace je českou zemskou vrstvou sdíleného rámce pro přiznání k DPH (l10n_cssk_vat_return_base). Vytváří české přiznání k DPH (DPHDP3): sada řádků DPHDP3 je namapována na daňové značky l10n_cz (VAT n Base / VAT n Tax) a 48 řádků založených na značkách se automaticky vypočítá z daňových značek zaúčtovaných řádků.

Je CE-čistá — čte přímo daňové značky jádra l10n_cz a nevyžaduje enterprise engine account_reports, takže funguje na Community i Enterprise. Export probíhá jako XML EPO Pisemnost / DPHDP3 (VetaD / VetaP / Veta1–Veta6) podle struktury exportu Odoo Enterprise.

Klíčové funkce

  • Sada řádků DPHDP3 (obrat23/dan23/…) namapovaná na daňové značky l10n_cz; 48 řádků základu/daně se automaticky počítá ze značek řádků zápisů.
  • Export XML EPO Pisemnost / DPHDP3 (VetaD / VetaP / Veta1–Veta6).
  • CE-čistá: čte daňové značky přímo, bez závislosti na account_reports — funguje na Community i Enterprise.

Použití

Účetnictví ▸ Výkazy ▸ Česká republika ▸ Přiznání k DPH. Vytvořte přiznání za období, Vypočítat pro naplnění řádků založených na značkách z účetních zápisů období, zkontrolujte řádky a následně Exportovat XML pro portál EPO.

Poznámka k rozsahu (v1): 48 řádků základu/daně se počítá automaticky; řádky nároku na odpočet (krácení koeficientem) a součty zadává/kontroluje účetní. Oficiální XSD EPO zatím není zapojeno (export ověřuje kořenový element a je dobře utvořený); pro validaci na úrovni podání jej doplňte.
