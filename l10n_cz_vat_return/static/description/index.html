Czech Republic — VAT Return (DPHDP3)

The Czech VAT return computed from the l10n_cz tax tags and exported as EPO Pisemnost/DPHDP3 XML

This app is the Czech country layer for the shared VAT-return framework (l10n_cssk_vat_return_base). It produces the Czech VAT return (přiznání k DPH / DPHDP3): the DPHDP3 line set is mapped to the l10n_cz tax tags (VAT n Base / VAT n Tax), and the 48 tag-based lines auto-compute from the posted move-line tags.

It is CE-clean — it reads the core l10n_cz tax tags directly and does not depend on the Enterprise account_reports engine, so it runs on both Community and Enterprise. Export is the EPO Pisemnost / DPHDP3 XML (VetaD / VetaP / Veta1–Veta6), mirroring the Odoo Enterprise export structure.

Key features

  • DPHDP3 line set (obrat23/dan23/…) mapped to the l10n_cz tax tags; the 48 base/tax lines auto-compute from the move-line tags.
  • EPO Pisemnost / DPHDP3 XML export (VetaD / VetaP / Veta1–Veta6).
  • CE-clean: reads tax tags directly, no account_reports dependency — works on Community and Enterprise.

Usage

Accounting ▸ Reporting ▸ Czech Republic ▸ Přiznání k DPH. Create a return for a period, Compute to populate the tag-based lines from the period's postings, review the lines, then Export XML for the EPO portal.

Scope note (v1): the 48 base/tax lines auto-compute; the deduction-claim lines (krácení coefficient) and the totals are entered/reviewed by the accountant. The official EPO XSD is not yet wired (the export validates the root element and is well-formed); add it for submission-grade validation.
