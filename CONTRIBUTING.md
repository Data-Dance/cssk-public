# Contributing

Thank you — contributions are welcome.

This repository is **generated**. Every module here is produced from a private
source repository, and the next sync overwrites whatever is committed here. A
change committed directly to this repository is lost, not merged.

## How a change reaches the code

1. **Open a pull request here.** This is the right place: it is where the code
   is readable and where review happens.
2. **Sign the contributor licence agreement.** The pull request will ask you to
   and will tell you exactly what to post. See [`cla/ICLA.md`](cla/ICLA.md) if
   you contribute as an individual, [`cla/CCLA.md`](cla/CCLA.md) if on behalf
   of an employer.
3. We apply the change to the source repository, preserving your authorship,
   and it returns here in the next sync. Your pull request is then closed with
   a link to the commit that carries it.

The CLA exists because some of these modules are also licensed commercially.
That is only possible for code owned outright, so we need the right to
relicense what you contribute. It does not take your copyright away.

## Reporting a problem

Open an issue here. Include the Odoo version, the module, and what you expected
to happen — statutory output especially, where "wrong" usually means
"wrong against a specific form and period".
