CZ/SK Partner Balance Confirmation (Saldokonto)

Signable open-item balance confirmations and the mutual set-off (zápočet) agreement, on Odoo core only

Slovak/Czech saldokonto — odsúhlasenie / potvrdenie zostatkov pohľadávok a záväzkov. A stored document that snapshots a partner's open receivables and payables as of a chosen date (reproducible — re-opening an old confirmation shows what was sent), tracks a state machine (draft → sent → agreed / disputed) and prints a PDF for the partner to countersign.

Depends on Odoo core only (account + mail + l10n_cssk_core). It complements OCA partner_statement (aging / activity view) by adding the signable confirmation document the aging report does not provide, plus a full mutual-offset (zápočet) agreement.

Key features

  • Balance confirmation (saldokonto): cssk.partner.confirmation + lines — a snapshot of open AR/AP move lines, totals, a state machine (SALDO/YYYY/NNNN sequence), chatter and a PDF. Disputed lines can be blocked (excluded from totals, still shown on the PDF).
  • Mutual offsetting (zápočet): cssk.partner.netting.agreement — loads a partner's open receivables and payables and auto-allocates the offset up to the netting amount = min(receivables, payables).
  • On posting, the netting builds a clearing journal entry (credit AR / debit AP) and reconciles the offset invoices (partial offsetting supported); ZAP/YYYY/NNNN sequence; undo via cancel with reversal.
  • Two legal modes: Bilateral (dohoda o vzájomnom započítaní — both parties sign before it takes effect) and Unilateral (jednostranné započítanie — a one-sided set-off effective on delivery, no countersignature).
  • Bilingual SK/EN PDF for both documents; the zápočet PDF switches wording between the bilateral agreement (two signatures) and the unilateral set-off notice (single signature, effective on delivery).

Usage

Accounting ▸ Customers ▸ Balance Confirmations for the saldokonto, and Accounting ▸ Vendors ▸ Netting Agreements (zápočet) for the mutual set-off. Create a document individually, or use the wizards below to issue confirmations in bulk / build a netting agreement for a partner. Compute, review, send / post, and print the PDF for countersigning.

Wizards

Generate Balance Confirmations (Accounting ▸ Customers ▸ Balance Confirmations ▸ Generate Confirmations)

What it does: issues balance confirmations for many partners at once.

How to use: pick the company, the as-of date and the confirmation type (receivables only / payables only / both); leave the partner list empty to issue for every partner with an open balance, then Generate. Each confirmation is created and computed, and the result list opens.

Create Netting Agreement (Accounting ▸ Vendors ▸ Netting Agreements (zápočet) ▸ Create Netting Agreement)

What it does: creates a netting agreement for a partner, auto-allocating the offset across the open AR/AP up to the balanced netting amount.

How to use: pick the company, the partner and the agreement date, then Create. The wizard loads the partner's open receivables and payables, computes min(receivables, payables) and greedily allocates that offset across the lines (raising if the partner has no mutually offsettable balances), then opens the new agreement to confirm / post.
