Bankové formáty CZ/SK — spoločné stavitele

Jednotný zdroj pravdy pre české/slovenské formáty platobných súborov ABO a MultiCash

Tento modul je spoločná knižnica za českými/slovenskými exportérmi bankových súborov Data Dance. Stavajú na ňom Community (account_payment_order) aj Enterprise (account_batch_payment) varianty account_abo / account_multicash, takže logika formátu je na jednom mieste.

Neobsahuje žiadne modely Odoo — len čisté pomocné funkcie importované cez odoo.addons.account_cz_bankfile_base.utils.*. Stavitele prijímajú zoznam normalizovaných záznamov BankPaymentItem, takže edíciám špecifické vrstvy ich napĺňajú buď z account.payment.line (CE), alebo z account.payment (EE) bez duplikovania logiky formátu.

Kľúčové funkcie

  • utils.abo.build_abo_file — zostaví súbor úhrad vo formáte ABO.
  • utils.multicash.build_multicash_file — zostaví súbory MultiCash CFD / CFU / CFA / MT101.
  • utils.common — parsovanie českého čísla účtu, normalizovaná položka BankPaymentItem odovzdávaná staviteľom a resolver symbolov VS/KS/SS (resolve_symbol: explicitná hodnota, inak token načítaný zo správy pre prijímateľa).

Použitie

Ide o knižničnú závislosť, nie koncovú aplikáciu. Inštaluje sa automaticky ako závislosť modulov account_abo / account_multicash. Na opätovné použitie staviteľov vo vlastnej vrstve zostavte zoznam BankPaymentItem a zavolajte príslušnú funkciu build_* importovanú z odoo.addons.account_cz_bankfile_base.utils.*.
