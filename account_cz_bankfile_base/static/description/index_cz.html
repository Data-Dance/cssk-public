Bankovní formáty CZ/SK — sdílené stavitele

Jednotný zdroj pravdy pro české/slovenské formáty platebních souborů ABO a MultiCash

Tento modul je sdílená knihovna za českými/slovenskými exportéry bankovních souborů Data Dance. Staví na něm jak Community (account_payment_order), tak Enterprise (account_batch_payment) varianty account_abo / account_multicash, takže logika formátu je na jednom místě.

Neobsahuje žádné modely Odoo — pouze čisté pomocné funkce importované přes odoo.addons.account_cz_bankfile_base.utils.*. Stavitele přijímají seznam normalizovaných záznamů BankPaymentItem, takže edicím specifické vrstvy je plní buď z account.payment.line (CE), nebo z account.payment (EE) bez duplikování logiky formátu.

Klíčové funkce

  • utils.abo.build_abo_file — sestaví soubor úhrad ve formátu ABO.
  • utils.multicash.build_multicash_file — sestaví soubory MultiCash CFD / CFU / CFA / MT101.
  • utils.common — parsování českého čísla účtu, normalizovaná položka BankPaymentItem předávaná stavitelům a resolver symbolů VS/KS/SS (resolve_symbol: explicitní hodnota, jinak token načtený ze zprávy pro příjemce).

Použití

Jde o knihovní závislost, nikoli koncovou aplikaci. Instaluje se automaticky jako závislost modulů account_abo / account_multicash. Pro opětovné použití stavitelů ve vlastní vrstvě sestavte seznam BankPaymentItem a zavolejte příslušnou funkci build_* importovanou z odoo.addons.account_cz_bankfile_base.utils.*.
