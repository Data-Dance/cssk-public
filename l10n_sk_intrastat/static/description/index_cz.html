Slovensko — INTRASTAT-SK (CE / OCA)

Oficiální XML INTRASTAT-SK INSTAT Finanční správy nad enginem OCA intrastat_product, počítáno CE-čistě

Tato aplikace je tenká národní vrstva nad deklaračním enginem OCA intrastat_product. Engine shromažďuje pohyby zboží v rámci EU a počítá seskupené řádky výkazu; tento modul je vykresluje jako oficiální XML INTRASTAT-SK INSTAT (instat62) slovenské Finanční správy přes sdílený renderer l10n_cssk_intrastat_base.

Jde o adaptér pro Community / OCA, licencovaný pod AGPL-3, protože dědí z AGPL enginu OCA. Sdílený renderer INSTAT je pod LGPL-3, takže varianta pro Enterprise — která místo toho jede na Odoo EE account_intrastat — jej může znovu použít bez přejímání AGPL.

Klíčové funkce

  • Národní adaptér nad deklaračním enginem OCA intrastat_product, CE-čistě (bez závislosti na Enterprise account_intrastat).
  • Vykresluje oficiální XML INTRASTAT-SK INSTAT (instat62) FS SR přes sdílený renderer l10n_cssk_intrastat_base.
  • Řádky výkazu pro přijetí / odeslání zboží počítané spodním enginem OCA.
  • Renderer INSTAT pod LGPL-3 je sdílený s variantou pro EE, takže oba adaptéry vydávají totožné zákonné XML.

Použití

Nainstalujte společně s enginem OCA intrastat_product na slovenské účtové osnově. Vytvořte v enginu OCA výkaz INTRASTAT za vykazované období, vygenerujte / spočítejte jeho řádky a poté exportujte XML INTRASTAT-SK INSTAT pro portál Finanční správy.
