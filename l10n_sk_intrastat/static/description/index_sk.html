Slovensko — INTRASTAT-SK (CE / OCA)

Oficiálne XML INTRASTAT-SK INSTAT Finančnej správy nad enginom OCA intrastat_product, počítané CE-čisto

Táto aplikácia je tenká národná vrstva nad deklaračným enginom OCA intrastat_product. Engine zhromažďuje pohyby tovaru v rámci EÚ a počíta zoskupené riadky výkazu; tento modul ich vykresľuje ako oficiálne XML INTRASTAT-SK INSTAT (instat62) slovenskej Finančnej správy cez spoločný renderer l10n_cssk_intrastat_base.

Ide o adaptér pre Community / OCA, licencovaný pod AGPL-3, pretože dedí z AGPL enginu OCA. Spoločný renderer INSTAT je tiež pod AGPL-3; variant pre Enterprise — ktorý namiesto toho beží na Odoo EE account_intrastat — ho používa, pretože ho Data Dance výlučne vlastní a poskytuje pod dvojitou licenciou.

Kľúčové funkcie

  • Národný adaptér nad deklaračným enginom OCA intrastat_product, CE-čisto (bez závislosti na Enterprise account_intrastat).
  • Vykresľuje oficiálne XML INTRASTAT-SK INSTAT (instat62) FS SR cez spoločný renderer l10n_cssk_intrastat_base.
  • Riadky výkazu pre prijatie / odoslanie tovaru počítané spodným enginom OCA.
  • Renderer INSTAT je spoločný s variantom pre EE, takže oba adaptéry vydávajú totožné zákonné XML.

Použitie

Nainštalujte spolu s enginom OCA intrastat_product na slovenskej účtovej osnove. Vytvorte v engine OCA výkaz INTRASTAT za vykazované obdobie, vygenerujte / vypočítajte jeho riadky a následne exportujte XML INTRASTAT-SK INSTAT pre portál Finančnej správy.
