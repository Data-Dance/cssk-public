Partner Autocomplete Dispatcher

Per-company dispatcher for pluggable partner-autocomplete providers

Technical framework that turns Odoo's partner autocomplete into a pluggable, per-company provider registry. Instead of a single hard-wired enrichment service, each company picks its Autocomplete provider, and the dispatcher routes name lookup, VAT lookup and company enrichment to the chosen one.

On its own this module ships only the registry and a do-nothing default provider; concrete providers (e.g. partner_autocomplete_ares_cz for the Czech ARES register) register themselves and become selectable. It also supports enrichment during data import and a bulk Update action on contacts.

Key features

  • Provider registry (partner.autocomplete.provider.registry) and an abstract provider interface (name autocomplete, read-by-VAT, enrich-company) that add-on modules extend.
  • Per-company provider selection — each res.company chooses its autocomplete provider; lookups are dispatched to it instead of the standard Odoo IAP service.
  • Enrichment during data import via an import_enrich_company field on partners.
  • Foundation for child-contact and bank-account enrichment returned by providers.

Usage

Install this module together with at least one provider add-on. In Settings ▸ General Settings ▸ Contacts enable Partner Autocomplete and choose the provider for the current company. From then on, partner autocomplete and enrichment use the selected provider. With only this module installed the default provider returns nothing — it exists to be extended.
