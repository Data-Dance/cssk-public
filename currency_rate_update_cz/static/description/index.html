Currency Rate Update CZ (ČNB)

Czech National Bank daily fixing as a provider for the OCA currency_rate_update framework

This app adds the Česká národní banka (Czech National Bank, ČNB) daily fixing as a res.currency.rate.provider for the OCA currency_rate_update framework. It is Community-compatible and does not require the Odoo Enterprise currency_rate_live feature.

The ČNB publishes one daily fixing (CZK against foreign currencies). For a CZK-base company the rate stored on res.currency.rate is Amount / Rate (foreign units per CZK) — for example EMU|euro|1|EUR|24.170 becomes 1 / 24.170 and Japan|yen|100|JPY|13.043 becomes 100 / 13.043.

Key features

  • ČNB daily-fixing provider for currency_rate_update.
  • Correct CZK-base conversion honouring the per-currency unit (the Amount column, e.g. 100 JPY).
  • Runs on Odoo Community — no Enterprise live-rate dependency.

Usage

In Settings ▸ Technical ▸ Currency Rate Providers create a provider, choose Česká národní banka (ČNB) as the service, select the currencies to track, and run the sync (manually or via the scheduled action). The pulled rates are written to res.currency.rate.
