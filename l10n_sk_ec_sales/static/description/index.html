Slovakia — Súhrnný výkaz (EC Sales List)

The Slovak EC sales list with codes 0/1/2 and the FS SR SDV XML export

This app produces the Slovak EC sales list (súhrnný výkaz) on top of the shared l10n_cssk_ec_summary_base framework. Intra-EU supplies are aggregated per (country, VAT number, transaction code) and exported as the FS SR SDV XML.

It depends on l10n_sk plus the shared framework — it does not depend on account_reports — so it runs on both Community and Enterprise, on Odoo 18.0 and 19.0.

Key features

  • Transaction codes: 0 = goods (dodanie tovaru), 1 = triangulation (trojstranný obchod – prostredná osoba), 2 = services (dodanie služby).
  • FS SR SDV XML export (template + stand-in XSD).
  • VIES preflight on the customers' VAT numbers before export.
  • CE-clean: no account_reports dependency — works on Community and Enterprise, 18.0 and 19.0.

Usage

Tag the intra-EU supply taxes with account.tax.cssk_ec_summary_code (0 % intra-community goods → 0, services → 2). Supplies to EU-registered customers using those taxes are then aggregated per (country, VAT, code). Create a statement for the period, Compute, review, then Export XML for the FS portal.

Status: aggregation, VIES preflight and the XSD-validated SDV export work. The XSD / template element names are a stand-in (see the base module) — replace with the official FS SR schema before live filing. Triangulation (code 1, middle party only) needs a country override + accountant sign-off.
