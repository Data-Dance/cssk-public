NOP KVERKOM Base

Přenosová vrstva pro slovenské QR Platby: mTLS REST klient a evidence transakcí

Základní integrace se slovenským Národním operátorem platieb (NOP), provozovaným společností KVERKOM, pro okamžité QR Platby z účtu na účet. Tento modul přináší mTLS REST klienta a autoritativní evidenci transakcí; sám o sobě neobsahuje žádnou logiku pokladny ani fakturace — integrace pro POS a faktury dodávají samostatné moduly, které na něm závisí.

Každá pos.config je svázána 1:1 s jednou pokladnicou NOP, jak vyžaduje slovenský rámec eKasa: jeden mTLS klientský certifikát identifikuje jednu fyzickou pokladnu. Subjekt certifikátu (VATSK a POKLADNICA id) se parsuje automaticky, se samostatnými sloty pro prostředí Integration a Production.

Klíčové funkce

  • Rozšíření pos.config nesoucí identitu NOP (VATSK, POKLADNICA id, prostředí), IBAN/název obchodníka a mTLS materiál pro každé prostředí (klientský certifikát, soukromý klíč, CA bundle).
  • nop.transaction — autoritativní evidence notifikací o platbách přijatých z banky přes NOP, s plným stavovým automatem (koncept, čekající, přijatá, potvrzená, nesoulad, zrušená, expirovaná, čekající vratka, vrácená …).
  • Služba NopClient — mTLS autentizovaný REST klient obalující generateNewTransactionId, getAllTransactions a getTransactionHistory.
  • Ověření integritního hashe (SHA-256 z IBAN|AMOUNT|EUR|endToEndId); notifikace, jejichž hash nebo částka nesouhlasí, jsou označeny jako nesoulad.
  • Dotazování s omezením frekvence (FOR UPDATE SKIP LOCKED) a záložní plánovaná úloha, která dočerpává čekající transakce, plus tisk dokladu o nepotvrzení.

Použití

Účetnictví ▸ Konfigurace ▸ NOP KVERKOM zobrazuje evidenci transakcí a pohled Dlužné vratky. Pokladnu nakonfigurujte na jejím záznamu konfigurace Pokladny: zvolte prostředí NOP, nahrajte eKasa klientský certifikát/klíč/CA pro dané prostředí a vyberte IBAN obchodníka — VATSK a POKLADNICA id se z certifikátu získají automaticky. Pro vlastní QR platební tok nainstalujte závislý modul (např. pos_nop_qr_platba_sk).
