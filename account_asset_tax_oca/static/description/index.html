Tax Depreciation — OCA bridge

Attach the CZ/SK tax-depreciation board to OCA account_asset_management (Community)

This bridge wires the country-neutral account_asset_tax core onto the OCA account_asset_management model — the Community-friendly asset framework, no Enterprise required. It adds the non-posted tax-depreciation board (daňové odpisy), the asset ↔ tax-line/event relations and the Tax Depreciation page on the asset form.

Install it together with the account_asset_tax core and a country data layer (l10n_cz_account_asset_tax / l10n_sk_account_asset_tax). It is mutually exclusive with the Enterprise bridge account_asset_tax_ee — only one asset implementation can be installed.

Key features

  • Mixes account.asset.tax.mixin into the OCA asset model and exposes the parallel tax-depreciation board.
  • Tax defaults inherited from the asset profile (account.asset.profile).
  • Disposal hook on the OCA removal flow (state='removed') recording the tax disposal event.
  • Deferred-tax accounting-residual reader and the posted-depreciation reader for the DPPO reconciliation.
  • Lifecycle-event buttons and the Tax Depreciation page on the asset form.

Validated on Odoo 19 Community (19CE-TEST): 11 integration tests green.

Usage

Open any asset to see its tax board next to the accounting board, on the Tax Depreciation page. The batch-compute, backfill, lifecycle-event, year-close and DPPO-reconciliation wizards are provided by the account_asset_tax core and operate on the board this bridge attaches.
