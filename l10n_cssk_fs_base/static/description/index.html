CZ/SK Financial Statements — Shared Framework

Country-neutral engine behind the Slovak Súvaha / VZS and Czech Rozvaha / VZZ — line trees from account-code balances, a comparison period and XSD-validated XML

The country-neutral engine behind the Slovak Súvaha (balance sheet) / Výkaz ziskov a strát (P&L) and Czech Rozvaha / Výkaz zisku a ztráty (VZZ). A hierarchical line tree where leaf lines are computed from account-code balances and parent lines aggregate, for a current and a comparison (prior) period.

CE-clean: the evaluator reads account.move.line balances directly (by account.account.code), so it does not depend on the Enterprise account_reports engine. It runs on Community and Enterprise, on Odoo 18.0 and 19.0. Country modules ship the line definitions (the account mapping), the XML template and the schema.

Key features

  • cssk.fs.statement.version — line definitions + statement kind (balance sheet / profit & loss) + template + schema. New legislation ships as a new version record.
  • cssk.fs.statement.line.def — three line kinds: accounts (account-code formula; balance sheet = as-of, P&L = period), aggregate (formula over line codes) and manual.
  • cssk.fs.statement (mail.thread) — computes the current and a comparison (prior) period, with per-line manual overrides preserved across recompute.
  • XSD-validated statutory XML export.

Scope note: this core computes a single (net) value per line. The SK Súvaha's 3-column Brutto / Korekcia / Netto split and the Poznámky / mikro variants are extensions on top.

Usage

Accounting ▸ Reporting ▸ Financial Statements. Use New Financial Statement to create one for a period, review the per-line detail (current vs prior period), adjust any manual lines, recompute, then Export XML. The line set, account mapping and schema come from the installed country module; statement versions live under the localization root menu.

Wizards

Create Financial Statement (Accounting ▸ Reporting ▸ Financial Statements ▸ New Financial Statement)

What it does: creates a financial statement for a period and computes it in one step.

How to use: pick the company, the statement version (filtered to the company's fiscal country) and the period (date from / date to), then Create; the wizard builds the cssk.fs.statement, runs the computation and opens the new statement.
