CZ/SK Intrastat — generátor XML INSTAT (základ)

Generátor XML INTRASTAT-SK INSTAT (instat62) nezávislý na edici, sdílený adaptéry pro Community (OCA) i Enterprise

Generátor a validátor XML INSTAT (instat62) pro INTRASTAT-SK, nezávislý na edici a bez závislostí. Vykresluje a validuje oficiální zprávu Finančnej správy INTRASTAT-SK (intrastat.financnasprava.sk, schéma instat62.xsd přibalené v data/) z normalizované hlavičky + slovníků řádků.

Závisí pouze na base — bez závislosti na OCA intrastat enginu nebo Odoo Enterprise account_intrastat — takže je LGPL-3 a mohou jej importovat jak AGPL Community adaptér (l10n_sk_intrastat), tak proprietární Enterprise adaptér. Nemá žádné uživatelské rozhraní; jde o sdílenou knihovnu pro vykreslování.

Klíčové funkce

  • cssk.instat.builder (AbstractModel) se dvěma vstupními body: build_instat_xml(header, lines) pro jedno hlášení / jeden tok (Community adaptér) a build_instat_envelope(env_header, decl_groups) pro jednu obálku s několika hlášeními, např. přijetí + odeslání (Enterprise adaptér).
  • Oba validují vykreslené XML proti přibalenému instat62.xsd a při chybě vyvolají výjimku.
  • Převod netMass / quantityInSU / invoicedAmount na celá čísla podle schématu.
  • Normalizované vykreslení Party / Address pro odesílatele obálky a PSI každého hlášení.

Použití

Tento modul nedodává žádné nabídky ani pohledy. Adaptéry INTRASTAT-SK pro Community / Enterprise volají self.env["cssk.instat.builder"].build_instat_xml(header, lines) (nebo build_instat_envelope(...)) s normalizovanou hlavičkou a slovníky řádků popsanými v models/cssk_instat_builder.py a validované XML vloží do hlášení.
