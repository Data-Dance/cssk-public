CZ/SK Intrastat — generátor XML INSTAT (základ)

Generátor XML INTRASTAT-SK INSTAT (instat62) nezávislý od edície, zdieľaný adaptérmi pre Community (OCA) aj Enterprise

Generátor a validátor XML INSTAT (instat62) pre INTRASTAT-SK, nezávislý od edície a bez závislostí. Vykresľuje a validuje oficiálnu správu Finančnej správy INTRASTAT-SK (intrastat.financnasprava.sk, schéma instat62.xsd pribalená v data/) z normalizovanej hlavičky + slovníkov riadkov.

Závisí iba od base — bez závislosti od OCA intrastat enginu alebo Odoo Enterprise account_intrastat — takže je LGPL-3 a môžu ho importovať tak AGPL Community adaptér (l10n_sk_intrastat), ako aj proprietárny Enterprise adaptér. Nemá žiadne používateľské rozhranie; ide o zdieľanú knižnicu na vykresľovanie.

Kľúčové funkcie

  • cssk.instat.builder (AbstractModel) s dvomi vstupnými bodmi: build_instat_xml(header, lines) pre jedno hlásenie / jeden tok (Community adaptér) a build_instat_envelope(env_header, decl_groups) pre jednu obálku s viacerými hláseniami, napr. prijatie + odoslanie (Enterprise adaptér).
  • Oba validujú vykreslené XML voči pribalenému instat62.xsd a pri chybe vyvolajú výnimku.
  • Prevod netMass / quantityInSU / invoicedAmount na celé čísla podľa schémy.
  • Normalizované vykreslenie Party / Address pre odosielateľa obálky a PSI každého hlásenia.

Použitie

Tento modul nedodáva žiadne ponuky ani pohľady. Adaptéry INTRASTAT-SK pre Community / Enterprise volajú self.env["cssk.instat.builder"].build_instat_xml(header, lines) (alebo build_instat_envelope(...)) s normalizovanou hlavičkou a slovníkmi riadkov opísanými v models/cssk_instat_builder.py a validované XML vložia do hlásenia.
