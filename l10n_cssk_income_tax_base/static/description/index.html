CZ/SK Income Tax Return — framework

Country-neutral engine for the corporate income-tax return (DPPO): versioned line definitions, an accounting-result + aggregate evaluator and XSD-validated XML

The shared, country-neutral engine for the corporate income-tax return (DPPO), mirroring the VAT-return and financial-statement frameworks. It depends on Odoo core only (account + mail + l10n_cssk_core), so it is Community-clean and runs on Odoo 18.0 and 19.0.

The country layer (e.g. l10n_sk_dppo) supplies the actual line set, the header mapping and the official schema. The accounting→tax transformation (the adjustment lines) is the accountant's domain — this framework auto-computes the accounting result and the formulaic spine and takes the rest as manual entry.

Key features

  • cssk.income.tax.version + line definitions — three line kinds: account (accounting result before tax), aggregate (the tax-computation spine, a formula over line codes) and manual (accountant adjustments — items increasing / decreasing the base); plus the submission types. New legislation ships as a new version record.
  • cssk.income.tax.return (mail.thread) — evaluator with manual overrides preserved and fed into dependent aggregate lines on recompute.
  • Submission state machine (draft → submitted) with amendment (supplementary / corrective) support.
  • XSD-validated statutory XML export.
  • Optional income-tax provision journal entry (591/341) — post and reverse.

Usage

Accounting ▸ Reporting ▸ Income Tax (DPPO). Use Generate to create a return for a period and version; the accounting result and the formulaic spine are computed automatically. Open the return, enter the manual adjustment lines (items increasing / decreasing the base), Compute to refresh the aggregates, then Export XML for submission. Optionally post the income-tax provision.

Wizards

Generate Income Tax Return (Accounting ▸ Reporting ▸ Income Tax (DPPO) ▸ Generate)

What it does: creates a DPPO return for a period and version and computes its lines in one step.

How to use: pick the company, the version, the submission type (filtered to the version) and the period (date from / date to), then Create; the wizard builds the cssk.income.tax.return, computes the lines and opens it. The period end must be on or after the start.
