Export plateb MultiCash

Export plateb ve formátech MultiCash (CFD/CFU/CFA/MT101) pro české banky

Tato aplikace generuje soubory plateb ve formátu MultiCash používané českými bankami — Česká spořitelna, KB, ČSOB, Raiffeisenbank, UniCredit a dalšími — z platebního příkazu OCA account.payment.order. Je čistě CE: staví na account_payment_order a sdílených stavitelích account_cz_bankfile_base, bez závislosti na Enterprise.

Vlastní vykreslení souboru je delegováno na account_cz_bankfile_base; tento modul mu pouze předává normalizované platební položky z řádků platby a podle platební metody určí cílový formát.

Klíčové funkce

  • CFD — tuzemské české úhrady a inkasa.
  • CFU — urgentní tuzemské české úhrady.
  • CFA — zahraniční (přeshraniční) platby.
  • MT101 — SWIFT Request For Transfer.
  • Variabilní / konstantní / specifický symbol (VS / KS / SS) na každém řádku platby, s náhradou, která načte token VS: / KS: / SS: ze zprávy pro příjemce, pokud je pole prázdné.
  • CFA / MT101 vyžadují, aby banka deníku měla vyplněný BIC, jinak je export zablokován s jasným hlášením.
  • Registruje příslušné výstupní platební metody (a vstupní CFD pro inkaso).

Použití

Nastavte u bankovního deníku platební metodu na požadovaný formát MultiCash (MultiCash CFD / CFU / CFA / MT101). Vytvořte platební příkaz z přijatých faktur jako obvykle (Účetnictví ▸ Dodavatelé ▸ Platební příkazy), vyplňte symboly VS/KS/SS na řádcích (nebo je nechte prázdné a použijte zprávu pro příjemce), potvrďte příkaz a zvolte Generovat platební soubor — vznikne soubor podle formátu (.cfd / .cfu / .cfa / .mt101) pro nahrání do banky.
