Export platieb MultiCash

Export platieb vo formátoch MultiCash (CFD/CFU/CFA/MT101) pre české banky

Táto aplikácia generuje súbory platieb vo formáte MultiCash používané českými bankami — Česká spořitelna, KB, ČSOB, Raiffeisenbank, UniCredit a ďalšími — z platobného príkazu OCA account.payment.order. Je čisto CE: stavia na account_payment_order a spoločných staviteľoch account_cz_bankfile_base, bez závislosti na Enterprise.

Samotné vykreslenie súboru je delegované na account_cz_bankfile_base; tento modul mu len odovzdáva normalizované platobné položky z riadkov platby a podľa platobnej metódy určí cieľový formát.

Kľúčové funkcie

  • CFD — tuzemské české úhrady a inkasá.
  • CFU — urgentné tuzemské české úhrady.
  • CFA — zahraničné (cezhraničné) platby.
  • MT101 — SWIFT Request For Transfer.
  • Variabilný / konštantný / špecifický symbol (VS / KS / SS) na každom riadku platby, s náhradou, ktorá načíta token VS: / KS: / SS: zo správy pre prijímateľa, ak je pole prázdne.
  • CFA / MT101 vyžadujú, aby banka denníka mala vyplnený BIC, inak je export zablokovaný s jasným hlásením.
  • Registruje príslušné výstupné platobné metódy (a vstupnú CFD pre inkaso).

Použitie

Nastavte v bankovom denníku platobnú metódu na požadovaný formát MultiCash (MultiCash CFD / CFU / CFA / MT101). Vytvorte platobný príkaz z prijatých faktúr ako obvykle (Účtovníctvo ▸ Dodávatelia ▸ Platobné príkazy), vyplňte symboly VS/KS/SS na riadkoch (alebo ich nechajte prázdne a použite správu pre prijímateľa), potvrďte príkaz a zvoľte Generovať platobný súbor — vznikne súbor podľa formátu (.cfd / .cfu / .cfa / .mt101) na nahranie do banky.
