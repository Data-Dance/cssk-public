[19.0.1.0.0] — 2026-11-12
-------------------------

Added
~~~~~

- First release in l10n_cssk, replacing ``l10n_cities_cz`` (15.0/16.0).
  The data is regenerated by ``tools/gen_base_location_data.py`` from the
  post's current list; ``data/SOURCE`` records the inputs and the counts.

Fixed (against ``l10n_cities_cz``)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

- **Okres is the okres.** The old data keyed districts by the kraj code, so
  there were 14 "okresy", each named after the first row of its kraj: every
  obec of Středočeský kraj sat in "okres Nymburk". All 77 okresy are now
  generated from their ČSÚ code (3100 = Hlavní město Praha), and Kraj Vysočina
  is no longer "Vysočina kraj".
- **Obce with the same name are separate cities.** The old data keyed an obec
  by its name, so the 591 names shared by several obce (Nová Ves ×14,
  Petrovice ×9 …) collapsed into one city each, carrying the PSČ of all of
  them: 912 of the 6,258 obce were missing. An obec is now keyed by its RÚIAN
  code.
- **Two obce of one name in one okres.** Březina (Brno-venkov) and Mezholezy
  (Domažlice) occur twice each within their okres, which ``res.city``'s
  uniqueness on name, state and country does not allow. Each carries its
  lowest PSČ in brackets: "Březina (66601)", "Březina (67905)".
