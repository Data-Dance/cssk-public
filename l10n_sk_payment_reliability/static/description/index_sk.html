SK spoľahlivosť dodávateľa — poskytovateľ z open dát FS

Slovenský poskytovateľ pre kontrolu spoľahlivosti dodávateľa: oznámené bankové účty a index daňovej spoľahlivosti z open dát FS

Táto aplikácia je slovenský národný poskytovateľ pre spoločnú CZ/SK kontrolu spoľahlivosti dodávateľa (l10n_cssk_payment_reliability). Dotazuje open-data API slovenskej Finančnej správy (iz.opendata.financnasprava.sk) na overenie oznámených bankových účtov dodávateľa a jeho indexu daňovej spoľahlivosti.

Kľúčové funkcie

  • Oznámené bankové účty — dátová sada ds_dph_iban (účty, ktoré platiteľ DPH oznámil správcovi dane), vyhľadané podľa IČ DPH.
  • Index daňovej spoľahlivosti — dátová sada ds_iz_ran (index daňovej spoľahlivosti: vysoko spoľahlivý / spoľahlivý / menej spoľahlivý), vyhľadané podľa IČO.
  • Zapája sa do spoločného základu spoľahlivosti, takže výsledok sa zobrazí tam, kde základ kontrolu prezentuje (partner / prijatá faktúra).

Použitie

Poskytovateľ potrebuje API kľúč k open dátam FS. Nastavte ho v Nastavenia ▸ Účtovníctvo ▸ "FS open-data API key" (registrácia na opendata.financnasprava.sk). Bez kľúča je poskytovateľ neaktívny a základ hlási „neskontrolované". S nastaveným kľúčom sa kontrola spoľahlivosti dodávateľa na partneroch a prijatých faktúrach zodpovie zo slovenských dátových sád.
