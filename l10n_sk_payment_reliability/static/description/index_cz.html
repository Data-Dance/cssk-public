SK spolehlivost dodavatele — poskytovatel z open dat FS

Slovenský poskytovatel pro kontrolu spolehlivosti dodavatele: zveřejněné bankovní účty a index daňové spolehlivosti z open dat FS

Tato aplikace je slovenský národní poskytovatel pro sdílenou CZ/SK kontrolu spolehlivosti dodavatele (l10n_cssk_payment_reliability). Dotazuje open-data API slovenské Finanční správy (iz.opendata.financnasprava.sk) za účelem ověření zveřejněných bankovních účtů dodavatele a jeho indexu daňové spolehlivosti.

Klíčové funkce

  • Zveřejněné bankovní účty — datová sada ds_dph_iban (účty, které plátce DPH oznámil správci daně), vyhledáno podle IČ DPH.
  • Index daňové spolehlivosti — datová sada ds_iz_ran (index daňovej spoľahlivosti: vysoce spolehlivý / spolehlivý / méně spolehlivý), vyhledáno podle IČO.
  • Zapojuje se do sdíleného základu spolehlivosti, takže výsledek se zobrazí tam, kde základ kontrolu prezentuje (partner / přijatá faktura).

Použití

Poskytovatel potřebuje API klíč k open datům FS. Nastavte jej v Nastavení ▸ Účetnictví ▸ "FS open-data API key" (registrace na opendata.financnasprava.sk). Bez klíče je poskytovatel neaktivní a základ hlásí „nezkontrolováno". S nastaveným klíčem se kontrola spolehlivosti dodavatele na partnerech a přijatých fakturách zodpoví ze slovenských datových sad.
