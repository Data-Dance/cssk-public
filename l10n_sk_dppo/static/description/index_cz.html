Slovensko — přiznání k dani z příjmů právnických osob (DPPO)

Slovenské přiznání DPPO: kompletní sada řádků, mapování hlavičky a export XML validovaný proti XSD dppo2025

Tato aplikace je slovenskou zemskou vrstvou rámce pro daň z příjmů (l10n_cssk_income_tax_base). Poskytuje formulář DPPOv25 — slovenské daňové přiznání k dani z příjmů právnických osob — jako verzovaná data: kompletní sadu řádků těla (r100 … r1192), kde r100 (výsledek hospodaření před zdaněním) se počítá z výsledovky a ostatní řádky zadává účetní přes UI pro přepis.

Hlavička se mapuje ze společnosti (DIČ, IČO, obchodní jméno, sídlo, zdaňovací období, typ přiznání). Oficiální dppo2025.xsd je přiloženo a export XML je proti němu validován.

Klíčové funkce

  • Sada řádků těla DPPOv25 (r100 … r1192) jako verzovaná data.
  • r100 se počítá automaticky z účetního výsledku; zbytek zadává účetní.
  • Mapování hlavičky ze společnosti (DIČ, IČO, obchodní jméno, sídlo, období, typ přiznání).
  • Export XML validovaný proti oficiálnímu schématu dppo2025 (XSD).

Použití

Účetnictví ▸ Výkazy ▸ Slovensko ▸ DPPO. Vytvořte přiznání za zdaňovací období, zkontrolujte/zadejte řádky těla (r100 se naplní z výsledovky) a poté Exportovat XML — export je před stažením validován proti dppo2025.xsd.

Poznámka k rozsahu (v1): modul automaticky počítá účetní výsledek a vytváří schématu odpovídající XML. Transformaci účetnictví→daň (úpravové řádky, odpočet ztráty, slevy na dani, minimální daň) provádí účetní a zadává ji ručně; meziřádkové výpočetní vzorce vyžadují validaci účetním, než budou automatizovány.
