==============================================
Slovak Bank Exchange Rates — Shared Download
==============================================

.. image:: https://img.shields.io/badge/licence-AGPL--3-blue.png
   :alt: License: AGPL-3

**Downloads and reads the VÚB banka and Tatra banka exchange-rate lists for the Slovak rate providers.**

Downloads and reads the exchange-rate lists that VÚB banka (the middle rate for transfers, *Devíza stred*) and Tatra banka publish on their websites, as euro-based rates. It has no screen, settings or data of its own. The services built on it are described with the Slovak exchange-rate providers.

It installs itself as a dependency of ``currency_rate_update_sk``; there is no reason to install it on its own.
