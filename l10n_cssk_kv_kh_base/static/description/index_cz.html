CZ/SK Kontrolní výkaz — sdílený rámec

Abstraktní jádro slovenského KV DPH a českého Kontrolního hlášení (KH DPH) — verzované šablony, mixiny řádků a export XML ověřeného proti XSD

Národně neutrální jádro slovenského Kontrolného výkazu DPH (KV DPH) a českého Kontrolního hlášení (KH DPH). Národní moduly (l10n_sk_kv_dph / l10n_cz_kh_dph) zapojují své konkrétní sady oddílů, limity a XML schémata.

Záměrně závisí pouze na jádru Odoo (account, mail, l10n_cssk_core) — bez account.report / account_reports — takže výkaz i jeho export XML jsou bez závislosti na Community / Enterprise, na Odoo 18.0 a 19.0.

Klíčové funkce

  • cssk.control.statement.version — verzovaná šablona + registr oddílů + typy podání + limit. Legislativní změny se dodávají jako nové záznamy verze, nikoli nové moduly.
  • cssk.control.statement — agregát výkazu (mail.thread; koncept → náhled → exportováno → podáno), s action_compute_lines a action_export_xml (vykreslení QWeb + validace XSD přes lxml).
  • Tři mixiny řádků — detail / souhrn / rekonciliace — k dědění konkrétními modely oddílů.
  • account.move.line — uložený cssk_control_section_code (počítaný národně přepsatelným resolverem, nejprve přenesení daňové povinnosti) + přepis pro více sazeb DPH.
  • account.tax — cssk_control_section_default + cssk_control_is_reverse_charge; account.journal — přepis výchozího oddílu.

Použití

Účetnictví ▸ Výkazy ▸ Kontrolní hlášení. Volbou Nové kontrolní hlášení vytvořte výkaz za období, Vypočítejte pro naplnění oddílů z účetních zápisů období, zkontrolujte detail po oddílech a poté Exportujte XML. Konkrétní sada oddílů, limity a schéma pocházejí z nainstalovaného národního modulu; verze výkazů jsou v kořenové nabídce lokalizace.

Průvodci

Vytvořit kontrolní hlášení DPH (Účetnictví ▸ Výkazy ▸ Kontrolní hlášení ▸ Nové kontrolní hlášení)

Co dělá: v jednom kroku vytvoří kontrolní hlášení za období a vypočítá je.

Jak používat: zvolte společnost, verzi výkazu (filtrovanou podle daňové země společnosti), typ podání, typ období (měsíční / čtvrtletní) a období (od / do), poté Vytvořit; průvodce sestaví cssk.control.statement, spustí výpočet a otevře nový výkaz.
