CZ/SK Kontrolný výkaz — zdieľaný rámec

Abstraktné jadro slovenského KV DPH a českého Kontrolného hlásenia (KH DPH) — verziované šablóny, mixiny riadkov a export XML overeného voči XSD

Národne neutrálne jadro slovenského Kontrolného výkazu DPH (KV DPH) a českého Kontrolného hlásenia (KH DPH). Národné moduly (l10n_sk_kv_dph / l10n_cz_kh_dph) zapájajú svoje konkrétne sady oddielov, prahy a XML schémy.

Zámerne závisí iba od jadra Odoo (account, mail, l10n_cssk_core) — bez account.report / account_reports — takže výkaz aj jeho export XML sú bez závislosti od Community / Enterprise, na Odoo 18.0 a 19.0.

Kľúčové funkcie

  • cssk.control.statement.version — verziovaná šablóna + register oddielov + typy podania + prah. Legislatívne zmeny sa dodávajú ako nové záznamy verzie, nie nové moduly.
  • cssk.control.statement — agregát výkazu (mail.thread; koncept → náhľad → exportované → podané), s action_compute_lines a action_export_xml (vykreslenie QWeb + validácia XSD cez lxml).
  • Tri mixiny riadkov — detail / súhrn / rekonciliácia — na dedenie konkrétnymi modelmi oddielov.
  • account.move.line — uložený cssk_control_section_code (počítaný národne prepísateľným resolverom, najprv prenesenie daňovej povinnosti) + prepis pre viaceré sadzby DPH.
  • account.tax — cssk_control_section_default + cssk_control_is_reverse_charge; account.journal — prepis predvoleného oddielu.

Použitie

Účtovníctvo ▸ Výkazy ▸ Kontrolný výkaz DPH. Voľbou Nový kontrolný výkaz vytvorte výkaz za obdobie, Vypočítajte na naplnenie oddielov z účtovných zápisov obdobia, skontrolujte detail po oddieloch a potom Exportujte XML. Konkrétna sada oddielov, prahy a schéma pochádzajú z nainštalovaného národného modulu; verzie výkazov sú v koreňovej ponuke lokalizácie.

Sprievodcovia

Vytvoriť kontrolný výkaz DPH (Účtovníctvo ▸ Výkazy ▸ Kontrolný výkaz DPH ▸ Nový kontrolný výkaz)

Čo robí: v jednom kroku vytvorí kontrolný výkaz za obdobie a vypočíta ho.

Ako používať: zvoľte spoločnosť, verziu výkazu (filtrovanú podľa daňovej krajiny spoločnosti), typ podania, typ obdobia (mesačné / štvrťročné) a obdobie (od / do), potom Vytvoriť; sprievodca zostaví cssk.control.statement, spustí výpočet a otvorí nový výkaz.
