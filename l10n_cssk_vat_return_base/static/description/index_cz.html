CZ/SK Přiznání k DPH — sdílený rámec

Zemsky neutrální engine pro slovenské DPHv25 a české DPHDP3 — číslované řádky z daňových značek, XML ověřené proti XSD

Zemsky neutrální engine pro slovenské daňové priznanie k DPH (DPHv25) a české přiznání k DPH (DPHDP3). Přiznání je pevná sada číslovaných řádků (riadky), z nichž každý je vypočten jako součet zůstatků položek se znaménkem, které nesou dané daňové značky, plus agregační řádky (součty) nad jinými řádky.

Čistě CE: daňové značky i pomocná funkce (account.account.tag._get_tax_tags) jsou v Odoo CE; tento modul přináší vlastní malý vyhodnocovač, takže nezávisí na EE enginu account_reports. Funguje na Community i Enterprise, na Odoo 18.0 a 19.0. Zemské moduly dodávají definice řádků, XML šablonu a schéma.

Klíčové funkce

  • cssk.vat.return.version — verzované definice řádků + XML šablona + schéma + typy přiznání.
  • cssk.vat.return.line.def — řádek je buď tags (vzorec daňových značek, např. -03, kde úvodní - je znaménko), aggregate (vzorec nad kódy jiných řádků, např. r04 + r06) nebo manual.
  • cssk.vat.return (mail.thread; koncept → náhled → exportováno → podáno) s vyhodnocovačem daňových značek a action_export_xml, který tvoří XML ověřené proti XSD.
  • cssk.vat.return.line — vypočtená hodnota každého řádku.
  • Vlastní vyhodnocovač daňových značek — bez závislosti na EE enginu account_reports.

Použití

Účetnictví ▸ Výkazy ▸ Přiznání k DPH. Pomocí Nové přiznání k DPH vytvořte přiznání za období (vypočte se jedním krokem), zkontrolujte číslované řádky naplněné z účetních zápisů období a poté Exportujte XML pro daňový portál. Definice řádků, šablona a schéma pocházejí z nainstalovaného zemského modulu; spravujte je v nabídce Verze přiznání k DPH.

Průvodci

Vytvořit přiznání k DPH (Účetnictví ▸ Výkazy ▸ Přiznání k DPH ▸ Nové přiznání k DPH)

Co dělá: vytvoří přiznání k DPH za období a jedním krokem jej vypočte.

Jak používat: zvolte společnost, verzi přiznání a typ přiznání, typ období (měsíční / čtvrtletní) a data období, poté stiskněte Vytvořit. Přiznání se vytvoří a jeho řádky se ihned vypočtou; otevře se formulář nového přiznání.
