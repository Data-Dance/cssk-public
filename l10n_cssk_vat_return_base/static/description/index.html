CZ/SK VAT Return — Shared Framework

Country-neutral engine behind the Slovak DPHv25 and Czech DPHDP3 VAT return — numbered lines from tax tags, XSD-validated XML

The country-neutral engine behind the Slovak daňové priznanie k DPH (DPHv25) and Czech přiznání k DPH (DPHDP3). The VAT return is a fixed set of numbered lines (riadky), each computed as a signed sum of move-line balances carrying given tax tags, plus aggregate lines (totals) over other lines.

CE-clean: the tax tags and the resolution helper (account.account.tag._get_tax_tags) live in Odoo CE; this module ships its own small evaluator, so it does not depend on the EE account_reports engine. Works on Community and Enterprise, on Odoo 18.0 and 19.0. Country modules supply the line definitions, the XML template and the schema.

Key features

  • cssk.vat.return.version — versioned line definitions + XML template + schema + statement types.
  • cssk.vat.return.line.def — a line is either tags (a tax-tag formula, e.g. -03, where a leading - is the sign), an aggregate (a formula over other line codes, e.g. r04 + r06) or manual.
  • cssk.vat.return (mail.thread; draft → preview → exported → submitted) with the tax-tag evaluator and action_export_xml producing XSD-validated XML.
  • cssk.vat.return.line — the computed value of each line.
  • Own tax-tag evaluator — no dependency on the EE account_reports engine.

Usage

Accounting ▸ Reporting ▸ VAT Return. Use New VAT Return to create a return for a period (it is computed in one step), review the numbered lines populated from the period's postings, then Export XML for the tax portal. Line definitions, the template and the schema come from the installed country module; manage them under the VAT Return Versions menu.

Wizards

Create VAT Return (Accounting ▸ Reporting ▸ VAT Return ▸ New VAT Return)

What it does: creates a VAT return for a period and computes it in one step.

How to use: choose the company, the return version and statement type, the period type (monthly / quarterly) and the period dates, then press Create. The return is created and its lines are immediately computed; the form opens on the new return.
