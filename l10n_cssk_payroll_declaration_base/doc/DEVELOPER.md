# Recorded insurance bases

The optional engine adapter is `_cssk_recorded_fund_bases`. An absent/noncallable
hook means the engine has no recorder and keeps its existing filing workflow.
An implemented hook returning False means that a particular supported payslip
has missing or inconsistent evidence. AccessError must propagate.

The plural reader returns records by payslip ID; `_collect_payslip_fund_bases`
owns the original/corrective policy. Originals warn and keep the existing
country fallback. Corrections refuse unless their explicit legacy review is
valid. Country consumers still own statutory wire mapping and rounding.
Native refund pairing and direction belong to the installed engine adapter.

`action_confirm_legacy_fund_bases` checks write access, draft correction state,
a nonempty reason and actual missing sources. It generates reviewer/time and
a digest of the report scope, reason and source facts. Stored scalar employment
facts supplement write_date because two edits can share a timestamp. No source
or personal data are copied into the digest field. Direct writes and context
defaults cannot supply approval fields; changing the reason clears approval.
The same valid review by the same user is idempotent. A new correction does not
copy it. An exported/retained XML is not regenerated by this approval action.

The action uses a private Python super-write for its own generated audit fields,
while preserving other mixins' write chain. No RPC/context capability can grant
the fallback. MVP/VPP/health/ELDP expose the reason/action and warning banner;
their inherited field labels need their own native translation references.
