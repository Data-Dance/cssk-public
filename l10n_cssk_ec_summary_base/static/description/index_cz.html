CZ/SK souhrnné hlášení — Sdílený rámec

Země-neutrální engine pro slovenský Súhrnný výkaz a české Souhrnné hlášení

Toto je země-neutrální engine pro slovenský Súhrnný výkaz a české Souhrnné hlášení (souhrnné hlášení / EC sales list). Obě mají stejný tvar řádku — jeden agregovaný řádek na (členský stát, DIČ zákazníka, kód transakce) — takže jeden řádkový model slouží oběma; národní moduly dodávají jen kódy, XML šablonu a schéma.

Závisí pouze na jádru Odoo (account, mail, l10n_cssk_core) — bez account_reports — takže je čistý pro Community/Enterprise i 18.0/19.0.

Klíčové funkce

  • cssk.ec.summary.statement.version — verzovaná šablona + schéma + typy.
  • cssk.ec.summary.statement (mail.thread; koncept → náhled → exportováno → podáno) s action_compute_lines a action_export_xml.
  • cssk.ec.summary.statement.line — agregovaný řádek.
  • account.tax.cssk_ec_summary_code — označuje daně z dodání do EU a jejich kód transakce.
  • Povinná předkontrola VIES před exportem (tvrdé zablokování — podané souhrnné hlášení s neplatným DIČ je v obou jurisdikcích sankcionováno).
  • Pipeline exportu XML ověřená proti XSD (předkontrola VIES → vykreslení QWeb → validace XSD → příloha).

Použití

Označte každou daň z dodání do EU jejím kódem transakce (krok nasazení), poté vytvořte hlášení za období v Účetnictví ▸ Výkazy ▸ Souhrnné hlášení ▸ Nové souhrnné hlášení, klikněte na Vypočítat pro agregované řádky, zkontrolujte je, spusťte předkontrolu VIES a Exportovat XML k podání. O zahrnutí rozhodují výhradně označené daně.

Průvodci

Vytvořit souhrnné hlášení (Účetnictví ▸ Výkazy ▸ Souhrnné hlášení ▸ Nové souhrnné hlášení)

Co dělá: vytvoří souhrnné hlášení za období a v jednom kroku ho vypočítá (cssk.ec.summary.wizard).

Jak používat: otevřete průvodce, zvolte firmu, verzi (filtrovanou podle daňové země firmy), typ hlášení, typ období (měsíční / čtvrtletní) a data od/do, poté Vytvořit. Hlášení se vytvoří, jeho řádky se vypočítají a otevře se formulář nového hlášení ke kontrole a exportu.
