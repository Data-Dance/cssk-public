CZ/SK EC Sales List — Shared Framework

The country-neutral engine behind the Slovak Súhrnný výkaz and Czech Souhrnné hlášení

This is the country-neutral engine behind the Slovak Súhrnný výkaz and Czech Souhrnné hlášení (EC sales list / recapitulative statement). The two have the same row shape — one aggregated line per (member-state, customer VAT, transaction code) — so a single line model serves both; country modules ship only the codes, XML template and schema.

Depends on Odoo core only (account, mail, l10n_cssk_core) — no account_reports — so it is Community/Enterprise- and 18.0/19.0-clean.

Key features

  • cssk.ec.summary.statement.version — versioned template + schema + types.
  • cssk.ec.summary.statement (mail.thread; draft → preview → exported → submitted) with action_compute_lines and action_export_xml.
  • cssk.ec.summary.statement.line — the aggregated line.
  • account.tax.cssk_ec_summary_code — marks intra-EU supply taxes and their transaction code.
  • Mandatory VIES preflight before export (hard block — a submitted EC list with an invalid VAT is penalised in both jurisdictions).
  • XSD-validated XML export pipeline (VIES preflight → QWeb render → XSD validate → attach).

Usage

Tag each intra-EU supply tax with its EC transaction code (a deployment step), then create a statement for a period from Accounting ▸ Reporting ▸ EC Sales List ▸ New EC Sales List, Compute the aggregated lines, review them, run the VIES preflight and Export XML for submission. Eligibility is driven entirely by the tagged taxes.

Wizards

Create EC Sales List (Accounting ▸ Reporting ▸ EC Sales List ▸ New EC Sales List)

What it does: creates an EC sales list statement for a period and computes it in one step (cssk.ec.summary.wizard).

How to use: open the wizard, pick the company, the version (filtered to the company's fiscal country), the statement type, the period type (monthly / quarterly) and the from/to dates, then Create. The statement is created, its lines are computed and the new statement form opens for review and export.
