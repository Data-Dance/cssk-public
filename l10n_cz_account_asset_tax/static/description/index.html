Tax Depreciation — Czech localization

The six Czech depreciation groups and coefficients (zákon 586/1992 Sb. §30–32) for the dual-depreciation core

The Czech data layer for the account_asset_tax dual-depreciation framework. It loads the six Czech depreciation groups (odpisové skupiny) with the straight-line rates (§31), the accelerated coefficients (§32) and the §30a extraordinary regime, verified against the 2026 consolidated text of zákon 586/1992 Sb.

This module is data only — it carries no models or views. Install it together with the core (account_asset_tax) and a bridge (account_asset_tax_ee for Enterprise or account_asset_tax_oca for OCA / Community) to attach the tax depreciation board (daňové odpisy) to actual assets.

Key features

  • All six Czech depreciation groups as data for the tax-depreciation engine.
  • §31 straight-line rates (first year / subsequent years / after technical improvement).
  • §32 accelerated coefficients (first year / subsequent years / after technical improvement).
  • The §30a extraordinary depreciation regime.
  • Verified against the 2026 consolidated text of zákon 586/1992 Sb.

Usage

Install core + one bridge + this country data layer (account_asset_tax + account_asset_tax_ee or account_asset_tax_oca + l10n_cz_account_asset_tax). The Czech groups then become selectable on assets, and the tax depreciation board is computed using the §31 / §32 / §30a rules. There is no separate configuration in this module — it only supplies the statutory group data.
