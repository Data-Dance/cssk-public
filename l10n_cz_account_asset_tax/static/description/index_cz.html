Daňové odpisy — česká lokalizace

Šest českých odpisových skupin a koeficientů (zákon 586/1992 Sb. §30–32) pro jádro dvojího odpisování

Česká datová vrstva pro rámec dvojího odpisování account_asset_tax. Načítá šest českých odpisových skupin (odpisové skupiny) s rovnoměrnými sazbami (§31), zrychlenými koeficienty (§32) a mimořádným režimem §30a, ověřenými proti konsolidovanému znění zákona 586/1992 Sb. z roku 2026.

Tento modul obsahuje pouze data — nepřináší žádné modely ani pohledy. Nainstalujte jej spolu s jádrem (account_asset_tax) a mostem (account_asset_tax_ee pro Enterprise nebo account_asset_tax_oca pro OCA / Community), abyste plán daňových odpisů (daňové odpisy) připojili ke skutečnému majetku.

Klíčové funkce

  • Všech šest českých odpisových skupin jako data pro engine daňových odpisů.
  • §31 rovnoměrné sazby (první rok / další roky / po technickém zhodnocení).
  • §32 zrychlené koeficienty (první rok / další roky / po technickém zhodnocení).
  • Mimořádný odpisový režim podle §30a.
  • Ověřeno proti konsolidovanému znění zákona 586/1992 Sb. z roku 2026.

Použití

Nainstalujte jádro + jeden most + tuto zemskou datovou vrstvu (account_asset_tax + account_asset_tax_ee nebo account_asset_tax_oca + l10n_cz_account_asset_tax). České skupiny pak lze vybrat na majetku a plán daňových odpisů se počítá podle pravidel §31 / §32 / §30a. V tomto modulu není žádné samostatné nastavení — dodává pouze zákonná data skupin.
