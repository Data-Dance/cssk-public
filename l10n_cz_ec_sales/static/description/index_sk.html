CZ Súhrnný výkaz (DPHSHV)

Česká národná vrstva zdieľaného rámca súhrnného výkazu s exportom XML EPO Pisemnost / DPHSHV

Tento modul je českou národnou vrstvou zdieľaného rámca súhrnného výkazu (l10n_cssk_ec_summary_base). Agreguje dodania do iného členského štátu EÚ podľa členského štátu, IČ DPH odberateľa a kódu plnenia — so zdedeným povinným overením IČ DPH (VIES) zo základného modulu — a exportuje českú XML správu EPO Pisemnost / DPHSHV.

Kľúčové funkcie

  • Agreguje dodania do iného členského štátu EÚ podľa (členský štát, IČ DPH odberateľa, kód plnenia) a využíva zdieľaný výkaz, riadky a povinné overenie IČ DPH (VIES) z modulu l10n_cssk_ec_summary_base.
  • Načítava kódy plnenia z account.tax.cssk_ec_summary_code (0 = tovar, 1 = trojstranný obchod, 2 = služby …).
  • Exportuje XML EPO Pisemnost / DPHSHV: jednu hlavičku VetaD, jeden blok platiteľa VetaP a jednu vetu VetaR za každý vykazovaný riadok partnera.
  • Obsahuje zákonnú verziu výkazu (2025) s typmi Řádné / Opravné / Následné.
  • Export je validovaný voči oficiálnemu XSD EPO DPHSHV (data/dphshv_epo2.xsd), ktoré je načítané na zázname verzie výkazu.

Použitie

Nainštalujte modul na českú spoločnosť, otvorte zdieľaný súhrnný výkaz, zvoľte českú verziu a obdobie, vypočítajte riadky a exportujte XML EPO Pisemnost / DPHSHV. Zaradenie plnenia vychádza z account.tax.cssk_ec_summary_code, preto sa uistite, že dane z dodaní do EÚ nesú správny kód plnenia a že má spoločnosť nastavený príslušný daňový úrad.
