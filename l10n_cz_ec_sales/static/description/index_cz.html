CZ Souhrnné hlášení (DPHSHV)

Česká národní vrstva sdíleného rámce souhrnného hlášení s exportem XML EPO Pisemnost / DPHSHV

Tento modul je českou národní vrstvou sdíleného rámce souhrnného hlášení (l10n_cssk_ec_summary_base). Agreguje plnění do jiného členského státu podle členského státu, DIČ odběratele a kódu plnění — se zděděným povinným ověřením DIČ (VIES) ze základního modulu — a exportuje českou XML zprávu EPO Pisemnost / DPHSHV.

Klíčové funkce

  • Agreguje dodání do EU podle (členský stát, DIČ odběratele, kód plnění) a využívá sdílené hlášení, řádky a povinné ověření DIČ (VIES) z modulu l10n_cssk_ec_summary_base.
  • Načítá kódy plnění z account.tax.cssk_ec_summary_code (0 = zboží, 1 = třístranný obchod, 2 = služby …).
  • Exportuje XML EPO Pisemnost / DPHSHV: jednu hlavičku VetaD, jeden blok plátce VetaP a jednu větu VetaR za každý vykazovaný řádek partnera.
  • Obsahuje zákonnou verzi hlášení (2025) s typy Řádné / Opravné / Následné.
  • Export je validován proti oficiálnímu XSD EPO DPHSHV (data/dphshv_epo2.xsd), které je načteno na záznamu verze výkazu.

Použití

Nainstalujte modul na českou společnost, otevřete sdílené souhrnné hlášení, zvolte českou verzi a období, vypočtěte řádky a exportujte XML EPO Pisemnost / DPHSHV. Zařazení plnění vychází z account.tax.cssk_ec_summary_code, proto se ujistěte, že daně z plnění do EU nesou správný kód plnění a že má společnost nastavený příslušný finanční úřad.
